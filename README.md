# KEMET: The Nile Flow 

AI-assisted Socratic English learning platform and n8n workflow automation for Grade 11 Egyptian Baccalaureate students.

## Project Structure
- `workflows/`: Exported n8n bot workflows and automation logic.
- `docs/`: Master project documentation, educational design rationales, and pedagogical frameworks.

## Cloud Media & Assets
Due to GitHub file size constraints, high-resolution multimedia learning assets and video demonstrations are hosted on Google Drive:
- [KEMET Media & Demonstration Assets](https://drive.google.com/drive/folders/1iAI3atOvTx3rQKMwr7tVsKtnM_GkkKZB)

## Getting Started
1. Import the workflow JSON from the `workflows/` directory into your n8n workspace.
2. Configure credentials in n8n for the Telegram Bot API and Gemini API.
3. Activate the webhook trigger to connect with your Telegram bot.
